# 산학 스택

삼육대학교 산학협력단 직원 카드로 쌓고, 맞추고, 결재하는 블록 퍼즐 게임입니다.
바이브코딩 실습 데모로 만들었습니다.

**▶ 바로 플레이: https://jinsuchung.github.io/sanhak-stack/**

설치나 로그인 없이 PC·휴대폰 브라우저에서 바로 할 수 있습니다. 화면이 좁으면 터치 버튼이 나옵니다.

## 규칙

- 직원 카드 2~3장으로 된 블록이 떨어집니다. 카드 색은 소속 팀을 나타냅니다.
- **줄 정리**: 가로 한 줄을 꽉 채우면 지워집니다.
- **협업 처리**: 같은 팀 카드 4장 이상이 맞닿으면 지워집니다.
- **연쇄**: 지워진 뒤 남은 카드는 아래로 떨어지고, 그 결과 또 지워지면 점수 배율이 올라갑니다.
- **결재 카드**: 가끔 나오는 빨간 단장 카드는 놓인 자리의 가로·세로 줄을 한꺼번에 지웁니다.
- 카드가 지워지면 그 직원의 직위와 담당업무가 "결재 처리 내역"에 뜨고 "직원 도감"에 등록됩니다. 14명을 모두 만나면 보너스 +1000점!

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 게임 전체 (HTML·CSS·JS 한 파일, 외부 라이브러리 없음) |
| `staff.js` | 직원 데이터 (`scrape.py`가 생성) |
| `scrape.py` | 산학협력단 홈페이지에서 직원 정보를 수집하는 스크립트 |

## 직원 데이터 갱신

데이터 출처는 [삼육대학교 산학협력단 '업무별 연락처'](https://www.syu.ac.kr/industry-academic-research/industry-academic-consortium/) 표입니다.
이름·팀·직위·담당업무만 저장하고 전화번호는 저장하지 않습니다.

홈페이지 내용이 바뀌면 아래 명령으로 `staff.js`를 다시 만든 뒤 커밋·푸시하세요. 추가 패키지 없이 Python 3 표준 라이브러리만 씁니다.

```bash
python3 scrape.py
```

새 팀이 생기면 `index.html`의 `GROUPS` 목록에 팀 이름을 추가해 색 그룹에 넣어 주세요. 목록에 없는 팀은 첫 번째 그룹(단 지도부) 색으로 표시됩니다.

## 로컬에서 실행

```bash
python3 -m http.server 8765
```

브라우저에서 http://localhost:8765 를 열면 됩니다. `index.html`을 파일로 바로 열어도 동작합니다.

## 배포

GitHub Pages가 `main` 브랜치 루트를 그대로 배포합니다. `main`에 푸시하면 1분 안팎으로 사이트에 반영됩니다.
